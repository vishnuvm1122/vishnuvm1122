# Professional Profile

I am a **Cybersecurity Analyst and Software Programmer** focused on building, analyzing, and improving secure software systems.

My work combines **cybersecurity, Python development, web application engineering, security monitoring, automation, and emerging AI security technologies**.

I am particularly interested in understanding how applications behave under real-world security conditions and developing practical solutions for authentication security, suspicious activity detection, monitoring, logging, and threat analysis.

# Development Philosophy

### 01 — Security First

Security should be considered throughout the development lifecycle rather than added at the end.

### 02 — Build Practical Systems

I prefer projects that solve realistic problems and demonstrate practical engineering skills.

### 03 — Automate Repetitive Work

Automation can improve consistency, reduce manual effort, and support security monitoring.

### 04 — Monitor What Matters

Good systems should provide useful logs, meaningful events, and actionable information.

### 05 — Continuous Improvement

Security and software engineering are continuous processes involving testing, analysis, learning, and improvement.
